# Data Cleaning Project

A Python-based data cleaning project using Pandas to transform raw retail sales data into clean and analysis-ready data.

## Project Overview

This project demonstrates a basic data cleaning workflow for a retail store sales dataset.

The raw dataset is processed using Python and Pandas to improve data quality and prepare it for further analysis.

## Data Cleaning Steps

- Loaded the raw CSV dataset using Pandas.
- Identified and handled missing values.
- Removed duplicate records.
- Checked and corrected data types.
- Cleaned and organized the dataset.
- Processed invalid or inconsistent data.
- Exported the cleaned dataset to a new CSV file.

## Technologies Used

- Python
- Pandas
- CSV

## Project Files

| File | Description |
|---|---|
| `clean_data.py` | Python script used for data cleaning |
| `retail_store_sales.csv` | Original raw dataset |
| `cleaned_retail_store_sales.csv` | Cleaned and processed dataset |

## Workflow

Raw Data → Data Cleaning → Clean Data → Ready for Analysis

## Purpose

The goal of this project is to demonstrate practical data cleaning and preprocessing using Python and Pandas.
